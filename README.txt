DÒNG CHẢY CỐ ĐÔ — prototype website\n\nMở index.html để xem prototype. admin.html để thử quản lý nội dung.\n\nĐây là prototype front-end: quản trị lưu trong localStorage của trình duyệt, chưa có backend, bảo mật, đăng nhập thật hay lưu trữ đồng bộ.\n\nĐể triển khai Vercel: đưa các file này lên một GitHub repository rồi import repository vào Vercel (static site, không cần build command; output directory để mặc định/ root). Có thể deploy tĩnh.\n\nĐể sử dụng thật lâu dài, tích hợp CMS/database/auth (ví dụ Supabase) và thiết lập quyền quản trị trước khi dùng công khai.\n
